# ArkWork ユーザーガイド（日本語）

[简体中文](./user-guide.zh-CN.md) | [English](./user-guide.en.md) | [한국어](./user-guide.ko.md)

ArkWork はローカルファーストの AI Agent デスクトップワークベンチです。ReAct 推理ループ（Reason → Act → Observation）を完全に可視化し、すべてのステップをリアルタイムで確認でき、いつでも一時停止・介入でき、タスク全体を追跡・再利用できます。

## 1. インストール

### 方法 A：インストーラーをダウンロード（推奨）

本リポジトリの [Releases](../../releases) ページから、お使いのプラットフォーム用パッケージをダウンロードしてください：

| プラットフォーム | ファイル |
|------------------|----------|
| macOS | `ArkWork-x.x.x-x64.dmg` |
| Windows | `ArkWork-Setup-x.x.x-x64.exe` |

**macOS**：dmg を開き、ArkWork を「アプリケーション」にドラッグします。
**Windows**：インストーラーを実行し、画面の指示に従います。

### 方法 B：ソースから実行

必要環境：Node.js ≥ 18、npm。

```bash
git clone https://github.com/<your-account>/ArkWork.git
cd ArkWork/app
npm install
npm run dev          # 開発モードで起動
npm run build:mac    # macOS 用パッケージを作成
npm run build:win    # Windows 用パッケージを作成
```

## 2. 初回起動：モデルの設定

ArkWork には LLM が同梱されていません。利用には最低 1 つのプロバイダー登録が必要です：

1. `⌘,` で設定を開く
2. **モデル** タブ → **モデルを追加** をクリック
3. 以下を入力：
   - **id / name**：任意の識別子と表示名
   - **kind**：プロバイダー種別 — `openai` / `anthropic` / `ollama` / `vllm`
   - **baseURL**：API エンドポイント（OpenAI 互換エンドポイントなら何でも可）
   - **apiKey**：API キー（Ollama などローカルモデルでは空欄可）
4. **テスト** をクリックして接続を確認し、保存
5. 入力欄下部のモデルチップから、いつでもモデルを切り替えられます

> ヒント：OpenAI 互換エンドポイント（DeepSeek、MiniMax、vLLM、LM Studio など）は `openai` 種別で追加できます。

## 3. 画面と基本概念

```
┌──────┬──────────────────────────┬───────────┐
│ 左ナビ │     中央ステージ           │  右ドック   │
│      │     （会話メイン）          │ (タスク情報)│
└──────┴──────────────────────────┴───────────┘
```

| 概念 | 説明 |
|------|------|
| **ワークスペース** | 1 フォルダ = 1 の独立したワークスペース。タスク・記憶・ナレッジベースはすべて内部に保存されます |
| **タスク** | Agent との一連のセッション。入力・記憶・ステップ履歴・成果物を完全保存し、続きの対話やエクスポートに対応 |
| **エージェント** | 人格設定を持つ実行者。用途ごとに作成し、スキルを割り当てられます |
| **スキル** | Agent が呼び出せる原子能力（shell、ファイル入出力、Web 取得など）。マーケットから追加も可能 |
| **ThoughtStream** | 思考とツール呼び出しを読みやすい単位に統合したナラティブ表示。実行中はライブ展開、完了後は折りたたみ |
| **チェックポイント** | 毎ターン自動保存。任意のイテレーションへワンクリックでロールバック |
| **プレビューウィンドウ** | Markdown / Web / コード / 画像 / 表のフローティングプレビュー |

### 4 層メモリシステム

| レイヤー | 内容 |
|----------|------|
| L1 ワーキングメモリ | 現在のタスクの要点リスト。**各項目のチェック**で次ターンのコンテキストへの注入を制御 |
| L2 ファイルメモリ | タスク中に生成された成果物ファイル |
| L3 策定/アーカイブ | 蒸留パイプラインが自動蓄積した長期知識と履歴アーカイブ |
| L4 ユーザープロファイル | タスク横断の好みや習慣 |

## 4. 日常的な使い方

### タスクの作成と実行

1. 下部の入力欄（Composer）に依頼を入力して Enter
2. Agent が Reason → Act ループを開始。ThoughtStream に各ステップの推論とツール呼び出しがリアルタイム表示されます
3. いつでも **一時停止 / 再開 / キャンセル** 可能
4. 完了後、右ドックで L1 メモリ・成果物・ログを確認できます

### コンテキストの制御

L1 メモリパネルの各項目のチェックボックスで、次ターンのコンテキストへの注入を決めます。不要な項目を外すことでトークンを節約し、Agent の集中度を上げられます。

### 任意のイテレーションへのロールバック

毎イテレーションにチェックポイントがあります。タスク詳細で対象を選ぶと、その時点まで巻き戻ります。

### 成果物のプレビュー

会話内の成果物カードをクリックすると、フローティングプレビュー（Markdown / ブラウザ / コードハイライト / 画像 / 表）で開きます。ドラッグして独立ウィンドウ化も可能です。

## 5. エージェントとスキル

- **エージェント作成**：左ナビのエージェントページ → 新規。名前・人格を記入し、割り当てるスキルにチェック
- **クイック切替**：`⌘1~9` でエージェントを切り替え
- **内蔵スキル**：shell ターミナル、ファイル読み書き/編集、glob/grep 検索、fetch-url、web-search、session-search、kb-search など 10 以上
- **権限モード**：全ツール呼び出しは権限ゲートを通過します。設定で許可ポリシーを調整可能（例：読み取り専用コマンドの自動承認）

---

## 6. ナレッジベース

ローカル文書を検索可能な私有ナレッジに変えます：

1. 左ナビの **ナレッジベース** パネルを開く
2. ローカルファイルを取り込む（PDF / Word / Markdown / テキストなどの一般的な形式に対応）
3. 自動的にチャンク分割され、全文インデックスが作成されます
4. タスクで KB を有効にすると、Agent が kb-search スキルで検索・参照できます

---

## 7. MCP とスキルマーケット

- **MCP**：設定で stdio タイプの MCP Server を追加すると、そのツールが Agent に注入されます
- **マーケット**：内蔵マーケットパネルでコミュニティスキルを閲覧・インストール。インストール済みスキルは各エージェントの選択肢に表示されます

---

## 8. 自動化タスク

左ナビの **オートメーション** パネル：

1. 新規作成し、cron 式で周期を定義（例：`0 9 * * 1-5` = 平日毎日 9:00）
2. タスク内容と対象ワークスペースを記入
3. 定刻に自動実行。実行履歴はパネルで確認できます

---

## 9. 表示言語の変更

**設定 → 言語** から選択できます：

- 简体中文（中国語、デフォルト）
- English（英語）
- 日本語
- 한국어（韓国語）

初回インストール時にシステム言語を自動検出します。切替は即時反映され、再起動は不要です。

## 11. データ保存とプライバシー

ArkWork は**ローカルファースト**アプリです：

- すべてのデータ（タスク・記憶・チェックポイント・KB インデックス・モデル設定）はローカルのユーザーデータディレクトリに保存されます：
  - macOS：`~/Library/Application Support/ArkWork/`
  - Windows：`%APPDATA%\ArkWork\`
  - Linux：`~/.config/ArkWork/`
- テレメトリは一切収集しません。通信は設定した API エンドポイントのみ
- API キーはローカルの設定ファイルにのみ保存されます

## 12. よくある質問

**Q：モデルの「テスト」に失敗する**
baseURL（`/v1` サフィックスの要否）、apiKey、ネットワークのプロキシ設定を確認してください。ローカルモデルはサーバー起動を確認してください（Ollama の既定は `http://127.0.0.1:11434`）。

**Q：macOS で一部フォルダへのアクセスを拒否される**
macOS のプライバシー保護（TCC）によるものです。「システム設定 → プライバシーとセキュリティ → ファイルとフォルダ」で ArkWork に許可を与えるか、書類/ダウンロードなど許可済みディレクトリにワークスペースを置いてください。

**Q：タスクデータはどこに保存される？消えることは？**
すべてローカルに永続化されます（上記参照）。アプリをアンインストールしてもディレクトリは削除されません。定期的なバックアップを推奨します。

**Q：完全にリセットするには？**
アプリを終了し、データディレクトリ内の `arkwork-data` フォルダを削除すると初期状態に戻ります（全タスクと設定が消えるため事前バックアップを）。

**Q：対応しているプロバイダーは？**
OpenAI、Anthropic、Ollama、vLLM、および OpenAI 互換エンドポイント全般（DeepSeek、MiniMax、SiliconFlow など）。
