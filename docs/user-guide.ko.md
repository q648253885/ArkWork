# ArkWork 사용자 가이드 (한국어)

[简体中文](./user-guide.zh-CN.md) | [English](./user-guide.en.md) | [日本語](./user-guide.ja.md)

ArkWork은 로컬 퍼스트 AI Agent 데스크톱 워크벤치입니다. ReAct 추론 루프(Reason → Act → Observation)를 완전히 시각화하여, 모든 단계를 실시간으로 확인하고 언제든 일시정지·개입할 수 있으며, 작업 전체를추적하고 재사용할 수 있습니다.

## 1. 설치

### 방법 A: 설치 패키지 다운로드 (권장)

이 저장소의 [Releases](../../releases) 페이지에서 플랫폼에 맞는 패키지를 다운로드하세요:

| 플랫폼 | 파일 |
|--------|------|
| macOS | `ArkWork-x.x.x-x64.dmg` |
| Windows | `ArkWork-Setup-x.x.x-x64.exe` |

**macOS**: dmg를 열고 ArkWork를 '응용 프로그램'으로 드래그합니다.
**Windows**: 설치 프로그램을 실행하고 안내에 따릅니다.

### 방법 B: 소스에서 실행

필요 환경: Node.js ≥ 18, npm.

```bash
git clone https://github.com/<your-account>/ArkWork.git
cd ArkWork/app
npm install
npm run dev          # 개발 모드로 실행
npm run build:mac    # macOS용 패키지 빌드
npm run build:win    # Windows용 패키지 빌드
```

## 2. 첫 실행: 모델 설정

ArkWork에는 LLM이 내장되어 있지 않습니다. 최소 1개의 프로바이더를 등록해야 합니다:

1. `⌘,` 로 설정 창을 엽니다
2. **모델** 탭 → **모델 추가** 클릭
3. 다음 항목을 입력:
   - **id / name**: 식별자와 표시 이름
   - **kind**: 프로바이더 유형 — `openai` / `anthropic` / `ollama` / `vllm`
   - **baseURL**: API 엔드포인트 (OpenAI 호환 엔드포인트라면 무엇이든 가능)
   - **apiKey**: API 키 (Ollama 같은 로컬 모델은 비워 두어도 됨)
4. **테스트** 를 클릭해 연결을 확인한 후 저장
5. 입력창 하단의 모델 칩에서 언제든 모델을 전환할 수 있습니다

> 팁: OpenAI 호환 엔드포인트(DeepSeek, MiniMax, vLLM, LM Studio 등)는 `openai` 유형으로 추가할 수 있습니다.

## 3. 화면 구성과 핵심 개념

```
┌──────┬──────────────────────────┬───────────┐
│ 왼쪽  │       중앙 스테이지        │  오른쪽 독  │
│ 내비  │      (대화 메인)           │ (작업 정보) │
└──────┴──────────────────────────┴───────────┘
```

| 개념 | 설명 |
|------|------|
| **워크스페이스** | 폴더 1개 = 독립된 워크스페이스 1개. 작업·기억·지식 베이스가 모두 그 안에 저장됩니다 |
| **태스크** | Agent와의 한 세션. 입력·기억·단계 이력·산출물을 완전 저장하며, 이어하기와 내보내기를 지원합니다 |
| **에이전트** | 페르소나를 가진 실행자. 용도별로 만들고 스킬을 바인딩할 수 있습니다 |
| **스킬** | Agent가 호출하는 원자 단위 기능(shell, 파일 입출력, 웹 가져오기 등). 마켓에서 추가 설치도 가능 |
| **ThoughtStream** | 생각과 도구 호출을 읽기 쉬운 단위로 통합한 내러티브 뷰. 실행 중에는 실시간 펼침, 완료 후 접힘 |
| **체크포인트** | 매 턴 자동 저장. 원하는 반복 시점으로 원클릭 롤백 |
| **미리보기 창** | Markdown / 웹 / 코드 / 이미지 / 표의 플로팅 미리보기 |

### 4계층 메모리 시스템

| 계층 | 내용 |
|------|------|
| L1 작업 기억 | 현재 작업의 요점 목록. **항목별 체크**로 다음 턴 컨텍스트 포함 여부 결정 |
| L2 파일 기억 | 작업 중 생성된 산출물 파일 |
| L3 큐레이션/아카이브 | 증류 파이프라인이 자동 축적한 장기 지식과 이력 아카이브 |
| L4 사용자 프로필 | 작업 간 선호와 습관 |

## 4. 일상적인 사용

### 태스크 만들고 실행하기

1. 하단 입력창(Composer)에 요청을 입력하고 Enter
2. Agent가 Reason → Act 루프를 시작합니다. ThoughtStream에 각 단계의 추론과 도구 호출이 실시간 표시됩니다
3. 언제든 **일시정지 / 재개 / 취소** 가능
4. 완료 후 오른쪽 독에서 L1 기억·산출물·로그를 확인합니다

### 컨텍스트 제어

L1 기억 패널에서 각 항목의 체크박스가 다음 턴 컨텍스트 주입 여부를 결정합니다. 불필요한 항목을 해제하면 토큰을 절약하고 Agent의 집중도를 높일 수 있습니다.

### 원하는 반복 시점으로 롤백

매 반복마다 체크포인트가 생성됩니다. 작업 상세에서 대상 체크포인트를 선택하면 그 시점으로 되돌아갑니다.

### 산출물 미리보기

대화 속 산출물 카드를 클릭하면 플로팅 미리보기(Markdown / 브라우저 / 코드 하이라이트 / 이미지 / 표)로 열립니다. 드래그해서 독립 창으로 분리할 수도 있습니다.

## 5. 에이전트와 스킬

- **에이전트 생성**: 왼쪽 내비의 에이전트 페이지 → 새로 만들기. 이름·페르소나를 입력하고 바인딩할 스킬 선택
- **빠른 전환**: `⌘1~9` 로 에이전트 전환
- **내장 스킬**: shell 터미널, 파일 읽기/쓰기/편집, glob/grep 검색, fetch-url, web-search, session-search, kb-search 등 10여 개
- **권한 모드**: 모든 도구 호출은 권한 게이트를 거칩니다. 설정에서 허용 정책 조정 가능(예: 읽기 전용 명령 자동 승인)

## 6. 지식 베이스

로컬 문서를 검색 가능한 사유 지식으로 바꿉니다:

1. 왼쪽 내비에서 **지식 베이스** 패널 열기
2. 로컬 파일 가져오기(PDF / Word / Markdown / 텍스트 등 일반 형식 지원)
3. 자동으로 청크 분할되고 전체 색인이 생성됩니다
4. 태스크에서 KB를 활성화하면 Agent가 kb-search 스킬로 검색·인용할 수 있습니다

---

## 7. MCP와 스킬 마켓

- **MCP**: 설정에서 stdio 유형의 MCP Server를 추가하면 해당 도구가 Agent에 주입됩니다
- **마켓**: 내장 마켓 패널에서 커뮤니티 스킬을 탐색·설치합니다. 설치된 스킬은 각 에이전트의 선택 목록에 나타납니다

---

## 8. 자동화 작업

왼쪽 내비의 **자동화** 패널:

1. 자동화를 새로 만들고 cron 표현식으로 주기를 정의(예: `0 9 * * 1-5` = 평일 매일 9시)
2. 작업 내용과 대상 워크스페이스를 입력
3. 예정 시각에 자동 실행되며, 실행 이력은 패널에서 확인할 수 있습니다

## 9. 인터페이스 언어 변경

**설정 → 언어** 에서 선택할 수 있습니다:

- 简体中文 (중국어, 기본값)
- English (영어)
- 日本語 (일본어)
- 한국어

첫 설치 시 시스템 언어를 자동 감지합니다. 전환은 즉시 적용되며 재시작이 필요 없습니다.

## 11. 데이터 저장과 프라이버시

ArkWork은 **로컬 퍼스트** 앱입니다:

- 모든 데이터(작업·기억·체크포인트·KB 색인·모델 설정)는 로컬 사용자 데이터 디렉터리에 저장됩니다:
  - macOS: `~/Library/Application Support/ArkWork/`
  - Windows: `%APPDATA%\ArkWork\`
  - Linux: `~/.config/ArkWork/`
- 텔레메트리를 전혀 수집하지 않으며, 통신은 설정한 API 엔드포인트로만 이루어집니다
- API 키는 로컬 설정 파일에만 저장됩니다

## 12. 자주 묻는 질문

**Q: 모델 '테스트'가 실패합니다**
baseURL(`/v1` 접미사 필요 여부), apiKey, 네트워크 프록시 설정을 확인하세요. 로컬 모델이라면 서버 실행 여부를 확인하세요(Ollama 기본값 `http://127.0.0.1:11434`).

**Q: macOS에서 일부 폴더 접근이 거부됩니다**
macOS 프라이버시 보호(TCC) 때문입니다. '시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더'에서 ArkWork에 권한을 부여하거나, 문서·다운로드처럼 이미 허용된 디렉터리에 워크스페이스를 두세요.

**Q: 작업 데이터는 어디에 저장되나요? 사라질 수 있나요?**
모두 로컬에 영구 저장됩니다(위 참조). 앱을 제거해도 해당 디렉터리는 삭제되지 않습니다. 정기적인 백업을 권장합니다.

**Q: 완전히 초기화하려면?**
앱을 종료한 뒤 데이터 디렉터리의 `arkwork-data` 폴더를 삭제하면 초기 상태로 돌아갑니다(모든 작업과 설정이 지워지므로 먼저 백업하세요).

**Q: 어떤 프로바이더를 지원하나요?**
OpenAI, Anthropic, Ollama, vLLM, 그리고 OpenAI 호환 엔드포인트 전반(DeepSeek, MiniMax, SiliconFlow 등).
