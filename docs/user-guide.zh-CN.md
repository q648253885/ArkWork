## 1. 安装

### 方式一：下载安装包（推荐）

前往本仓库的 [Releases](../../releases) 页面，下载对应平台的安装包：

| 平台 | 文件 |
|------|------|
| macOS | `ArkWork-x.x.x-x64.dmg` |
| Windows | `ArkWork-Setup-x.x.x-x64.exe` |

**macOS**：打开 dmg，将 ArkWork 拖入「应用程序」即可。
**Windows**：运行安装器，按提示完成安装。

### 方式二：从源码运行

前置要求：Node.js ≥ 18、npm。

```bash
git clone https://github.com/<your-account>/ArkWork.git
cd ArkWork/app
npm install
npm run dev          # 开发模式启动
npm run build:mac    # 打包 macOS 安装包
npm run build:win    # 打包 Windows 安装包
```

## 2. 首次启动：配置模型

ArkWork 本身不内置大模型，需要接入至少一个 LLM Provider 才能工作：

1. 按 `⌘,`（或点击 设置）打开设置窗口
2. 进入 **模型** 标签页 → 点击 **添加模型**
3. 填写：
   - **id / name**：自定义标识与显示名
   - **kind**：服务商类型，支持 `openai` / `anthropic` / `ollama` / `vllm`
   - **baseURL**：API 地址（OpenAI 兼容端点均可）
   - **apiKey**：密钥（本地模型如 Ollama 可留空）
4. 点击 **测试** 确认连通后保存
5. 在输入框底部的模型 chip 上可随时切换当前使用的模型

> 提示：任何 OpenAI 兼容端点（DeepSeek、MiniMax、vLLM、LM Studio 等）都可以用 `openai` 类型接入。

## 3. 界面与核心概念

```
┌──────┬──────────────────────────┬───────────┐
│ 左栏 │        主对话区            │  右侧坞    │
│ 导航 │      （CenterStage）       │(RightDock)│
└──────┴──────────────────────────┴───────────┘
```

| 概念 | 说明 |
|------|------|
| **工作区 Workspace** | 一个文件夹 = 一个独立工作区。任务、记忆、知识库均落盘在工作区内，互不干扰 |
| **任务 Task** | 一次完整的 Agent 会话。保存输入、记忆、步骤流与产物文件，支持续聊与导出 |
| **智能体 Agent** | 带人格设定的执行者。可为不同场景创建不同 Agent 并绑定技能 |
| **技能 Skill** | Agent 可调用的原子能力（shell、文件读写、网页抓取等），也可从市场安装 |
| **ThoughtStream** | 叙事流视图：把"思考 + 工具调用"合并为可读单元，运行中实时展开，完成后折叠 |
| **检查点 Checkpoint** | 每轮自动存档，出问题可一键回滚到任意迭代 |
| **预览窗 PreviewWindow** | 浮窗预览 Markdown / 网页 / 代码 / 图片 / 数据表产物 |

### 四层记忆体系

| 层级 | 内容 |
|------|------|
| L1 工作记忆 | 当前任务的要点清单，**每条可手动勾选**是否进入下一轮上下文 |
| L2 文件记忆 | 任务过程中产生的产物文件 |
| L3 策展/档案记忆 | 由蒸馏管线自动沉淀的长期知识与历史归档 |
| L4 用户画像 | 跨任务的偏好与习惯 |

## 4. 日常使用

### 创建并运行任务

1. 在底部输入框（Composer）输入需求，回车发送
2. Agent 开始 Reason → Act 循环：右侧 ThoughtStream 实时展示每步推理与工具调用
3. 需要介入时随时 **暂停 / 恢复 / 取消**
4. 任务结束后可在右侧坞查看 L1 记忆、产物文件与日志

### 控制上下文

L1 记忆面板中，每条记忆前的复选框决定它是否注入下一轮对话上下文——去掉无关条目可以省 token、让 Agent 更专注。

### 回滚到任意迭代

每次迭代都有检查点。在任务详情中选择目标检查点即可回滚，之后的分支重新开始。

### 预览产物

点击对话中的产物卡片，会在浮窗中打开对应渲染器（Markdown / 浏览器 / 代码高亮 / 图片 / 表格），支持拖拽为独立浮窗。

## 5. 智能体与技能

- **创建 Agent**：左栏进入智能体页 → 新建，填写名称、人格描述，勾选要绑定的技能
- **快速切换**：`⌘1~9` 在常用 Agent 之间切换
- **内置技能**：shell 终端、文件读写/编辑、glob/grep 检索、fetch-url 网页抓取、web-search 联网搜索、session-search 会话检索、kb-search 知识库检索等 10+
- **权限模式**：每个工具调用受权限门禁保护；可在设置中调整放行策略（例如允许只读命令自动执行）

---

## 6. 知识库

把本地文档变成 Agent 可检索的私有知识：

1. 左栏进入 **知识库** 面板
2. 导入本地文件（支持 PDF / Word / Markdown / 文本等常见格式）
3. 应用会自动切块并建立全文索引
4. 在任务中启用对应知识库后，Agent 可通过 kb-search 技能检索引用

---

## 7. MCP 与技能市场

- **MCP**：设置中可添加 stdio 类型的 MCP Server，其工具会注入给 Agent 使用
- **技能市场**：内置市场面板可浏览、安装社区技能；已安装技能出现在 Agent 的可选列表中

---

## 8. 自动化任务

左栏进入 **自动化** 面板：

1. 新建自动化，用 cron 表达式定义周期（如 `0 9 * * 1-5` 工作日每天 9 点）
2. 填写任务内容与目标工作区
3. 到点自动执行，执行记录可在面板中查看

## 9. 切换界面语言

**设置 → 语言** 中可选择：

- 简体中文（默认）
- English
- 日本語
- 한국어

首次安装时会自动探测系统语言；切换立即生效，无需重启。

## 11. 数据存储与隐私

ArkWork 是**本地优先**应用：

- 所有数据（任务、记忆、检查点、知识库索引、模型配置）保存在本机用户数据目录：
  - macOS：`~/Library/Application Support/ArkWork/`
  - Windows：`%APPDATA%\ArkWork\`
  - Linux：`~/.config/ArkWork/`
- 不上传任何遥测数据；与 LLM Provider 的通信仅限你配置的 API 端点
- API Key 仅存储在本机配置文件中

## 12. 常见问题

**Q：模型「测试」失败？**
检查 baseURL 是否正确（注意是否需要 `/v1` 后缀）、apiKey 是否有效、网络是否需要代理。本地模型确认服务已启动（如 Ollama 默认 `http://127.0.0.1:11434`）。

**Q：macOS 上访问某些文件夹被拒绝？**
这是 macOS 隐私保护（TCC）限制。在「系统设置 → 隐私与安全性 → 文件与文件夹」中给 ArkWork 授权，或将工作区放在「文档」「下载」等已授权目录。

**Q：任务数据存在哪里？会不会丢？**
全部落盘在本地用户数据目录（见上文），卸载应用不会删除该目录；建议自行定期备份。

**Q：如何彻底重置？**
退出应用后删除用户数据目录中的 `arkwork-data` 文件夹即可恢复初始状态（会清除所有任务与配置，请先备份）。

**Q：支持哪些模型服务商？**
OpenAI、Anthropic、Ollama、vLLM，以及一切 OpenAI 兼容端点（DeepSeek、MiniMax、硅基流动等）。
